# 英语单词气泡增加中文释义

## 摘要

英语课程里长按（或点按）单词会弹出音标气泡，目前只显示单词、音标和朗读按钮。本次在气泡中增加中文释义：课程词优先读内置词典，离线也能立即显示；内置词典没有的词再走有道联网兜底。纯前端 + 一份新数据文件，不引入新依赖。

## 现状分析

- 气泡实现：[tappable_phonetic_text.dart](file:///d:/workspace/github_code/GlobalVillage/lib/features/lesson/widgets/tappable_phonetic_text.dart)
  - `showPhoneticBubble` / `_PhoneticBubbleOverlay` 展示「单词 + 音标 + 喇叭」，`bubbleMaxWidth = 220`。
  - 文案为硬编码中文（`查询中…`、`暂无音标，可点喇叭`、`朗读`），不需要走 `AppStrings`。
- 查询服务：[phonetic_lookup_service.dart](file:///d:/workspace/github_code/GlobalVillage/lib/core/services/phonetic_lookup_service.dart)
  - 本地 `assets/phonetics/en_ipa.json` 优先；未命中走有道 `https://dict.youdao.com/jsonapi`。
  - 本地命中直接返回，**不联网**；网络失败不写否定缓存；`_cache` 容量 200。
  - 有道响应里 `ec.word[0].trs[].tr[].l.i` 就是中文释义（已实际请求 `pharmacist` 验证：`["n. 药剂师，药师"]`），当前解析只取 `usphone/ukphone`。

- 课程语料只有句子级 `sentence` / `prompt`，**没有词级中文释义**，因此需要单独的数据源。
- 内容包机制：音标表可通过 `phonetics/en_ipa` 下发（[content_documents.dart](file:///d:/workspace/github_code/GlobalVillage/lib/data/sources/content_documents.dart)、[content_catalog.dart](file:///d:/workspace/github_code/GlobalVillage/server/lib/content_catalog.dart)），发布前由 `_validatePhonetics` 校验为「字符串到字符串」的 JSON 对象；新释义表沿用同一格式即可直接复用。
- 现有测试：[phonetic_lookup_service_test.dart](file:///d:/workspace/github_code/GlobalVillage/test/phonetic_lookup_service_test.dart)、[phonetic_bubble_test.dart](file:///d:/workspace/github_code/GlobalVillage/test/phonetic_bubble_test.dart)。

## 变更方案

### 1. 新增本地中文释义数据与生成脚本

**新文件** `tools/build_course_gloss.py`（仿照 `build_course_ipa.py`）

- 复用同样的抽词逻辑：遍历 `assets/courses/*.json`，用 `[A-Za-z']+` 提取小写单词（长度 > 1 或为 `a` / `i`）。
- 数据源：ECDICT（MIT，<https://github.com/skywind3000/ECDICT>）的 `ecdict.csv`（约 66MB），首次运行下载到 `tools/.cache/ecdict.csv`，之后复用缓存。
- 用 `csv.DictReader` 一次遍历，按 `word.lower()` 命中课程词，读取 `translation` 字段。
- 清洗规则（固定，避免气泡里出现长段落）：
  1. 按字面量 `\n` 切行（ECDICT 用 `\\n` 分隔义项）；
  2. 优先保留不以 `[网络]` 开头的行；全部都是网络释义时退回第一行；
  3. 取第一条，去掉行首 `[网络]`，合并多余空白；
  4. 超过 40 个字符时截断并加 `…`。
- 输出 `assets/phonetics/en_zh.json`：`{ "reply": "v. 回答；回复", ... }`，`ensure_ascii=False`、`sort_keys=True`、两空格缩进。
- 脚本末尾打印 `course words / written / missing`，missing 样例用于人工核对。
- 运行一次并提交生成结果；`pubspec.yaml` 已注册 `assets/phonetics/` 目录，无需改配置。

**`.gitignore`**：增加 `tools/.cache/`，避免把 66MB 的 ECDICT 原始文件提交进仓库（与现有本地缓存目录惯例一致）。

### 2. 查询服务支持释义

文件：[phonetic_lookup_service.dart](file:///d:/workspace/github_code/GlobalVillage/lib/core/services/phonetic_lookup_service.dart)

- `PhoneticResult` 增加 `final String? meaning;`（中文释义）。
- 构造函数增加 `Map<String, String>? localGloss`，用于测试注入。
- `ensureLocalLoaded()` 同时加载音标与释义：
  - 音标：`packId: 'phonetics/en_ipa'`，`assets/phonetics/en_ipa.json`（现有逻辑不变）；
  - 释义：`packId: 'phonetics/en_zh'`，`assets/phonetics/en_zh.json`；
  - 两者都用 `readOverlaidText`，读取失败时该表退化为空 Map，不影响音标。
- `_resolve(key)` 改为合并逻辑：
  1. 本地 `ipa`、`meaning` 都有 → 直接返回合并结果并缓存，**不联网**；
  2. 任一缺失 → 调 `_fetchYoudao` 一次，合并：`ipa = 本地 ?? 远端`，`meaning = 本地 ?? 远端`；
  3. 远端命中（有音标或有释义）→ 缓存合并结果并返回；
  4. 远端确认无词条但本地有音标 → 返回仅含音标的本地结果，**不写否定缓存**（下次仍可补释义）；
  5. 本地、远端都没有 → 仅远端确认无词条时缓存 `null`；网络失败不缓存（保持现状）。
- `_parseYoudao` 增加释义解析：
  ```dart
  String? _parseMeaning(Map<String, dynamic> first) {
    final trs = first['trs'];
    if (trs is! List) return null;
    final parts = <String>[];
    for (final item in trs) {
      if (item is! Map) continue;
      final tr = item['tr'];
      if (tr is! List) continue;
      for (final entry in tr) {
        final l = entry is Map ? entry['l'] : null;
        final i = l is Map ? l['i'] : null;
        if (i is String && i.trim().isNotEmpty) parts.add(i.trim());
        if (i is List) {
          for (final s in i) {
            if (s is String && s.trim().isNotEmpty) parts.add(s.trim());
          }
        }
      }
    }
    return parts.isEmpty ? null : _cleanMeaning(parts.join('；'));
  }
  ```
  `_cleanMeaning`：合并空白、去首尾、超过 60 字符截断加 `…`。
- 解析结果判定从「必须有 phone」改为「phone 或 meaning 任一存在即为命中」，只有释义时也返回（`ipa` 为 null，气泡显示现有占位文案）。
- 缓存键、并发合并（`_inflight`）、200 条上限、网络超时 6 秒均保持不变。

## 假设与决策

- 翻译来源按用户选择：**本地优先 + 联网兜底**。课程词基本都能离线显示释义；ECDICT 未收录的词（如专有名词、变形）才联网。
- 不引入新的运行时依赖，不新增词典页；释义只出现在现有音标气泡里。
- 释义用中文，不随 UI 语言切换（气泡里现有文案也全是中文，保持一致）。
- ECDICT 为 MIT 许可，仅在构建期使用，不打包原始 CSV；生成物是课程词的少量释义。
- 生成脚本抽词规则与 `build_course_ipa.py` 保持一致，避免音标有、释义缺的词比例异常。
- 线上有道响应结构以实际验证的 `ec.word[0].trs[].tr[].l.i` 为准；解析失败按「无释义」处理，不影响音标。
