用户询问"账号信息保存在哪里"后得知：账号与进度纯本地存储（Hive，`/data/data/.../app_flutter/`），换手机/卸载即丢失。本次新增**备份码导出/导入**功能：把账号（昵称+密码哈希+盐）与该账号全部进度序列化为一段 JSON 备份码，用户可复制保存；在新设备粘贴即可恢复账号与进度。无需后端，离线可用。

##  Proposed Changes

### 1. 新建 `lib/core/services/backup_service.dart`

```dart
class BackupService {
  // 导出当前登录账号（非游客）的备份 JSON 字符串；游客返回 null
  Future<String?> exportBackup()
  // 导入备份 JSON：写回 user + 进度 + 设置会话；失败返回错误文案
  Future<String?> importBackup(String jsonStr)
}
```

- 导出 JSON 结构：`{"version":1, "exportedAt":毫秒, "user":{nickname,passwordHash,salt,createdAt}, "progress":[{lessonId,completed,score,correctCount,totalCount,completedAt},...]}`；进度取 box 中所有 `nickname|` 前缀的 key。
- 导入：解析校验（version=1、user 字段齐全）→ `users.put(nickname, user)` → 逐条 `progress.put('$nickname|${p.lessonId}', ...)` → `session.put('current', nickname)`。同名账号覆盖（备份码即凭证）。
- 依赖 UserStore + 直接 Hive.box（与现有 store 一致）。

### 2. `lib/app/auth_controller.dart` 新增

```dart
/// 恢复会话（备份导入后调用）
Future<void> restoreSession(String userKey) async {
  await repository.store.setSession(userKey);
  state = AuthState(userKey: userKey);
}
```
（UserRepository 的 store 字段需确认为 public，若 private 则在 UserRepository 加 `setSession` 透传方法。）

### 3. `lib/features/learning_path/learning_path_page.dart` 关于弹窗加两个按钮

在"退出登录"按钮上方加：
- **备份数据**：游客→提示"游客数据不支持备份，请先注册账号"；否则导出 → 弹窗显示备份码（`SelectableText` + `SingleChildScrollView`，等宽小字）+ "复制备份码"按钮（`Clipboard.setData`，复制后 SnackBar 提示）。
- **恢复数据**：弹窗含多行 `TextField`（"粘贴备份码"）+ "粘贴"按钮（读剪贴板填入）+ "恢复"按钮 → `importBackup` → 成功：`authProvider.notifier.restoreSession(nickname)` + `progressRevisionProvider` +1 + 关弹窗 + SnackBar"恢复成功"；失败：弹窗内红字显示错误。

## 假设与决策

- 备份码为明文 JSON（含哈希不含明文密码），用户自行保管；恢复即视为凭证，符合本地单机定位。
- 游客不支持备份（无账号实体），提示先注册。
- 不做二维码形式备份码（太长），仅文本复制。
