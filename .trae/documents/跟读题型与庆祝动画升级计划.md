# 跟读题型 + 闯关动画升级计划（v0.8.0）

## 概述

两个功能：
1. **跟读练习新题型（speaking）**：每课追加 1 道跟读题（56 课共 56 题），用 `speech_to_text` 识别发音、与目标句做词级相似度打分，≥60% 算对并计入 70% 通关正确率；识别不可用时降级为"跟读完成"直接通过，保证不卡关。
2. **闯关庆祝动画升级**：循环彩纸雨 + 徽章旋转光环与星星粒子 + 庆祝音效与震动 + 米娅/里奥角色欢呼 + 分级文案。

## 现状分析（已核实）

- 题型：`ExerciseType { translateChoice, wordBank, listeningChoice, fillBlank }`（[course.dart](file:///D:/workspace/github_code/地球村/lib/data/models/course.dart)），每课固定 8 题：3 选择 + 2 词块 + 2 听力 + 1 填空，u1-u14 分布一致，共 448 题。
- 答题流程：[lesson_page.dart](file:///D:/workspace/github_code/地球村/lib/features/lesson/lesson_page.dart) `_buildExercise` switch 分发 widget；`submit(answer)` 归一化比对，首错移到队尾重做、二次错出队；`_onCheck` 播 correct/wrong 音效。
- 音频复用：`TtsService.speakExercise` 播 `audio/listening/{exercise.id}.mp3`，缺失回退系统 TTS——给 e9 生成同名 mp3 即可零改动复用。
- 庆祝页：[award_celebration.dart](file:///D:/workspace/github_code/地球村/lib/features/lesson/widgets/award_celebration.dart) 白底 + 一次性 64 片彩纸爆发 + 徽章 elasticOut 缩放，已尊重 `MediaQuery.disableAnimationsOf`。
- AndroidManifest **未声明任何权限**；无录音/语音识别依赖。
- 数据测试：[course_loader_test.dart](file:///D:/workspace/github_code/地球村/test/course_loader_test.dart) 断言 14 单元 / 56 课 / 每课 8 题 / 448 题，需同步更新。
- 数据生成：`.trae/gen_units7to10.py` 的 `append_units` 模式可复用；`.trae/gen_audio.py` 幂等生成听力 mp3。

## 改动明细

### A. 跟读题型

1. **pubspec.yaml**：加 `speech_to_text: ^7.0.0`（沙箱走 pub.flutter-io.cn 镜像）。
2. **android/app/src/main/AndroidManifest.xml**：
   - `<uses-permission android:name="android.permission.RECORD_AUDIO"/>`
   - `<queries>` 块加 `<intent><action android:name="android.speech.RecognitionService"/></intent>`（Android 11+ 可见性）。
3. **lib/data/models/course.dart**：`ExerciseType` 加 `speaking`。JSON 沿用现有字段：`sentence`/`answer` = 目标英文句，`prompt` = 中文，`options=[]`，无 `sentenceWithBlank`。
4. **.trae/gen_speaking.py**（新增）：复用 `gen_units7to10.append_units` 同风格——读 JSON，给每课 append e9（已存在则跳过，幂等）。目标句取该课句对 1 的英文（每课 6 句对中口语价值高且长度适中者）；写回 `ensure_ascii=True, indent=2`。
5. **.trae/gen_audio.py**（扩展）：为 e9 生成 `audio/listening/uXlYe9.mp3`（edge-tts Jenny，语速 -20%，与听力题一致），存在即跳过。共 56 个。
6. **lib/core/utils/similarity.dart**（新增）：纯 Dart 词级相似度——normalize（小写/去标点/压缩空白）后按词做 Levenshtein，`score = 1 - dist / max(len1, len2)`。独立文件便于单测。
7. **lib/features/lesson/widgets/speaking_widget.dart**（新增）：
   - 布局参考 listening_choice_widget：中文 prompt + 英文句卡片 + 喇叭（`speakExercise`，进题自动播一遍）+ 底部大麦克风按钮。
   - 麦克风：点击开始/停止 `SpeechToText.listen(localeId: 'en_US', partialResults)`，实时显示识别文本；停止后算相似度并显示分数（如"82% 很像了！"）。
   - ≥0.6：把 `exercise.sentence` 作为答案提交（走现有 `submit` 判对）；<0.6：提交识别原文（必判错，进入"首错重做"流程），提示"再试一次"。
   - 权限拒绝/`initialize` 失败（模拟器、无 Google 语音服务）：显示降级提示 + "跟读完成"按钮，点击提交 `exercise.sentence`（算对）。
   - 状态通过 `ValueKey` 重建机制天然隔离（现有机制）。
8. **lib/features/lesson/lesson_page.dart**：`_buildExercise` switch 加 `ExerciseType.speaking => SpeakingWidget(...)`。

### B. 庆祝动画升级（重写 award_celebration.dart 视觉层）

- 主 `AnimationController(duration: 2600ms)` 保留用于入场；新增 `_rainController` `repeat()` 循环驱动彩纸雨。
- `_ConfettiRainPainter`：每片彩纸用 index 派生伪随机（x 起点、速度、摆幅、相位、颜色），从顶部持续下落 + 正弦摆动，出底回收循环。
- 徽章：外层 `Transform.rotate` + SweepGradient 金色光环（CustomPainter 圆弧），周围 8 颗星星粒子脉动；保留 elasticOut 入场。
- 角色欢呼：米娅（face_3/蓝）与里奥（face_6/绿）圆形头像从两侧 `AnimatedScale` 弹入，轻微上下跳动。
- 分级文案：`award` 无正确率数据——从 result_page 传入 `bool isPerfect`，全对显示"完美通关！"，否则"闯关成功！"。
- 音效+震动：进入页面播 `assets/sounds/celebrate.wav`（用 generate_sounds.ps1 生成欢快琶音，约 1.2s）+ `HapticFeedback.lightImpact()`；失败静默。
- 全程尊重 `MediaQuery.disableAnimationsOf`（值置 1、不循环）。
- `result_page.dart`：构造 `AwardCelebration` 时多传 `isPerfect: widget.result.accuracy >= 1.0`。

## 风险与备注

- `speech_to_text` 在国产手机依赖系统语音识别服务（Google/厂商）；降级路径已保证不卡关。
- 跟读判错会占用"首错重做"机会，二次错自动跳过（现有机制），不会死循环。
- 加 e9 后老用户已完成的课不受影响（进度按 lessonId，不校验题数）。
