# 登录界面功能实施计划

## Context（背景）

App 目前启动直接进入学习路径页，无用户概念。用户要求"增加登录界面，研究常用设计模式再设计"。经研究（Duolingo onboarding 分析、onboarding 模式综述）并与用户确认，采用商用软件惯例 + 多邻国延迟登录模式：

- **本地账号**（无后端）：昵称 + 密码注册/登录，密码加盐哈希存储，会话持久化（重启自动登录），进度按账号隔离，提供退出/切换账号入口。
- **允许游客**：欢迎页"开始学习"以游客进入（userKey='guest'），登录/注册为可选入口。
- 设计模式要点：零摩擦首屏（大 Logo + 一句价值主张 + 单一主按钮）、内联校验错误、按钮禁用灰态、延迟登录（先体验价值再注册保存进度）。

## 现状关键事实

- 存储分层：`Store`(Hive 封装) → `Repository`(业务) → `Provider`。`ProgressStore.boxName='lesson_progress'`，box 在 `main()` 打开；`LessonProgressAdapter` typeId=0（[progress.dart](file:///d:/workspace/github_code/地球村/lib/data/models/progress.dart)）。
- 路由：顶层单例 `appRouter`（GoRouter，initialLocation '/'，无 redirect）[router.dart](file:///d:/workspace/github_code/地球村/lib/app/router.dart)。
- `main.dart`：Hive init → registerAdapter → openBox → ProviderScope；`EnglishVillageApp` 用 `course.when(data: MaterialApp.router(routerConfig: appRouter))`。
- `progressRepositoryProvider` 构造注入 `{store, course}`；`ProgressRepository` 内部只调 `store.get(lessonId)/save`。
- 可复用：`PushableButton`（onPressed==null 自动灰态）、`AppColors`、关于弹窗 Logo 样式（[learning_path_page.dart](file:///d:/workspace/github_code/地球村/lib/features/learning_path/learning_path_page.dart)）。
- `crypto` 已在 pubspec.lock 作为传递依赖（直接声明即可）；`test/progress_repository_test.dart` 直接 `new ProgressStore()`，改构造需同步更新。

## 实施步骤

### 1. 数据模型 `lib/data/models/user.dart`（新建）
`User{nickname, passwordHash, salt, createdAt}` + 手写 `UserAdapter`（typeId=1，仿 LessonProgressAdapter 写法）。

### 2. 数据源 `lib/data/sources/user_store.dart`（新建）
仿 ProgressStore：`usersBoxName='users'`（Box<User>，key=昵称）、`sessionBoxName='auth_session'`（Box<String>，key 'current' 存 userKey）。API：`getUser/putUser/currentSession/setSession/clearSession`。

### 3. 仓库 `lib/data/repositories/user_repository.dart`（新建）
依赖 UserStore + `package:crypto`。
- 盐：`Random.secure()` 16 字节 hex；哈希 = `sha256(utf8('$salt:$password'))`。
- `String? register({nickname, password, confirm})`：昵称 2–12 字符（`characters.length` 防 emoji 代理对）、禁止含 `|`、不重复；密码 ≥6；确认一致。成功写 User + setSession，返回 null；失败返回错误文案。
- `String? login({nickname, password})`：不存在→"该昵称未注册"；哈希不符→"密码错误"；成功 setSession。
- `loginAsGuest()` → setSession('guest')；`logout()` → clearSession()。

### 4. 进度隔离
- [progress_store.dart](file:///d:/workspace/github_code/地球村/lib/data/sources/progress_store.dart)：改构造 `ProgressStore({required this.userKey})`；`get/save` 内部 Hive key 用 `'$userKey|$lessonId'`。新增静态 `migrateLegacy()`：把不含 `|` 的旧 key 重写为 `guest|<key>` 并删旧 key（幂等）。
- [progress_repository.dart](file:///d:/workspace/github_code/地球村/lib/data/repositories/progress_repository.dart)：**不动**。

### 5. 状态层 `lib/app/auth_controller.dart`（新建）
`AuthState{userKey, hasSession, isGuest}`；`AuthController extends StateNotifier<AuthState>`，构造时同步读 session 恢复；包装 repo 的 register/login/loginAsGuest/logout 并更新 state（注册/登录返回错误文案透传）。
[providers.dart](file:///d:/workspace/github_code/地球村/lib/app/providers.dart) 新增：`userStoreProvider`、`userRepositoryProvider`、`authProvider`；`progressStoreProvider` 改为 `ProgressStore(userKey: ref.watch(authProvider).userKey)`（依赖单向，无循环）。

### 6. 路由 [router.dart](file:///d:/workspace/github_code/地球村/lib/app/router.dart)
顶层单例改为 `final goRouterProvider = Provider<GoRouter>((ref) {...})`，`ref.watch(authProvider)`；加 `redirect`：
- 无会话且不在 `/welcome /login /register` → `/welcome`
- 有会话且在这三页 → `/`
- 否则 null
路由表新增 3 条。登录/退出跳转一律靠 auth 变化 → router 重建 → redirect 自动导航，**不手动 context.go**。

### 7. [main.dart](file:///d:/workspace/github_code/地球村/lib/main.dart)
`registerAdapter(UserAdapter())`；追加 `openBox<User>('users')`、`openBox<String>('auth_session')`；`await ProgressStore.migrateLegacy()`（runApp 前）；`routerConfig: ref.watch(goRouterProvider)`。

### 8. UI `lib/features/auth/`（新建 3 页 + widgets/auth_text_field.dart 统一圆角输入框）
- **welcome_page.dart**：多邻国风格——大 Logo（Icons.school 绿底圆角，复用关于弹窗样式）+ 标题"地球村" + 一句价值主张 + `PushableButton('开始学习')`（绿，loginAsGuest）+ 次按钮（蓝 `AppColors.blue/blueDark`，push '/login'）+ 底部 `v$kAppVersion`。
- **login_page.dart**：AppBar 返回 + 昵称/密码（obscureText + 眼切换）+ 内联红字错误 + PushableButton 登录 + 底部"没有账号？去注册"。ConsumerStatefulWidget + TextEditingController。
- **register_page.dart**：昵称/密码/确认密码 + 内联校验红字 + 注册即登录。
- [learning_path_page.dart](file:///d:/workspace/github_code/地球村/lib/features/learning_path/learning_path_page.dart) 关于弹窗加"退出登录 / 切换账号"按钮：确认对话框 → `ref.read(authProvider.notifier).logout()`。

## 风险与决策

- 旧进度迁移归属 `guest|`：老用户注册新账号后进度从零（游客进度仍在）——接受此限制，MVP 不做进度转入账号。
- 课中不切号（退出入口仅首页关于弹窗），`progressRepositoryProvider` 始终指向当前账号，安全。
- `progressRevisionProvider` 跨账号共享无副作用。
- course.when 门控保留：/welcome 也等课程加载（毫秒级），redirect 不必处理 course 未就绪。
