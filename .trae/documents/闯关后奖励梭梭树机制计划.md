# 闯关后奖励梭梭树机制

## Context

用户希望给「地球村」增加蚂蚁森林式激励：每次闯关成功（正确率 ≥ 70%，含重玩）奖励 1 棵「梭梭树」。树有成长阶段（种子→幼苗→小树→梭梭大树），通关庆祝页展示本次获得的树与当前成长阶段，升阶时给特别提示。目标是增强持续学习动力，机制轻量、与现有徽章体系并存。

**关键设计决策**：现有 `reward_attempts` Hive box 每次通关存一条记录（attemptId 幂等、`userKey|` 前缀隔离账号），**box 总条数 = 累计通关次数 = 梭梭树总数**。树计数直接从该 box 派生，无需新增 store/box/provider；备份恢复（backup_service v2 整包导出 attempts）也自动覆盖，零额外改动。

## 改动清单

### 1. 新增 `lib/data/models/tree_growth.dart`（纯 Dart 逻辑）
- `TreeStage` 常量表：`{seed 种子 0, sprout 幼苗 1, smallTree 小树 5, bigTree 梭梭大树 15}`，每项含 `minTrees/名称/图标说明`。
- `TreeStage stageFor(int count)`：取满足 `minTrees <= count` 的最高阶段。
- 升阶判断：`stageFor(count) != stageFor(count - 1) && count > 0`（比 `count == minTrees` 稳健，阈值可调不出错）。

### 2. `lib/data/repositories/reward_repository.dart`
- 加 `int get treeCount => store.attempts.length;`（已按 userKey 过滤，天然账号隔离）。

### 3. `lib/features/lesson/result_page.dart`
- `_saveResult()` passed 分支：award 成功后（`_award = award` 同一 setState 里）读取 `ref.read(rewardRepositoryProvider).treeCount` 存入新状态字段 `_treeCount`，传给 `AwardCelebration`。
- 注意：仅在 `award != null` 时读树数；`_award` 展示区块可加一行小的树计数提示（与徽章对称）。

### 4. `lib/features/lesson/widgets/award_celebration.dart`
- 加可选参数 `treeCount`（`int?`，默认 null 保持现有测试/调用兼容）。
- 徽章计数文本（`$title徽章 +1` / `累计 N 枚`）下方加树区块，**压缩为一行**：阶段图标（种子 `Icons.grain` / 幼苗 `Icons.eco` / 小树 `Icons.park` / 大树 `Icons.forest`）+ `梭梭树 +1 · 累计 N 棵 · 阶段名`；升阶时该行替换为高亮的 `梭梭树成长为「小树」啦！`（避免小屏多行堆积，已有 SingleChildScrollView 兜底）。
- 配色用 `AppColors.green` 系，与徽章金色区分。
