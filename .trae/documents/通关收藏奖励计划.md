# 通关收藏奖励计划

## Summary

在每次真实答题达到 70% 通关时，获得所属单元的一枚主题徽章；重复通关会增加该徽章的收藏次数。结算页短暂呈现获得奖励，首页提供「收藏」入口查看 14 个单元的徽章和累计次数。隐藏跳关不发奖励。不增加小游戏、货币或兑换商店。

## Current State Analysis

- `lib/features/lesson/lesson_page.dart` 完成练习后将 `LessonResult` 经路由 extra 传给结算页；`lib/features/lesson/result_page.dart` 在首帧回写成绩，展示奖杯、得分、正确率、用时。
- `lib/data/repositories/progress_repository.dart` 的 `recordResult` 决定通过与否，`skipCurrentLesson` 会写入已完成但零题零分的进度；进度由 `ProgressStore` 按账号隔离。
- `lib/main.dart` 初始化 Hive；`lib/app/providers.dart` 注入仓库；`lib/app/router.dart` 管理首页、课程与结果路由；首页 `lib/features/learning_path/learning_path_page.dart` 已有进度和关于入口。
- `lib/core/services/backup_service.dart` 使用 version=1 的 JSON 备份账号和学习进度，旧备份需要持续可导入；目前没有收藏数据模型和素材。
- `assets/courses/course_beginner.json` 有 14 个单元、每单元 4 课，可用课程单元 id/title 作为徽章定义的稳定来源。

## Proposed Changes

1. `lib/data/sources/reward_store.dart`、`lib/data/repositories/reward_repository.dart`：新建 Hive `Box<String>`（如 `reward_attempts`），key 为 `$userKey|$attemptId`，value 为 `unitId`；每次成功答题仅记录一条尝试，按单元聚合次数。`awardForPassedAttempt(lessonId, attemptId)` 验证课程中存在该课且尝试 id 未写入，同一 id 再调用不重复发奖；返回单元信息及最新次数。仅从实际通过的结果页调用，不从 `skipCurrentLesson` 调用。账号切换通过与进度相同的 `authProvider.userKey` 隔离；不同账号相同尝试 id 不冲突。
2. `lib/features/lesson/lesson_page.dart`、`lib/features/lesson/result_page.dart`：每次进入课程答题页产生一次唯一 attemptId，并经 `LessonResult` 携带到结算页；结果页先 `recordResult` 再按 `result.passed` 发奖励。等待持久化完成后显示本单元主题徽章、获得 `+1` 和累计次数，以约 300-500 ms 的轻量缩放/淡入动效呈现；无须等待动画即可返回。失败结算保持现状；写入失败显示现有成绩但不谎称已获得奖励，允许明确重试保存或重新进入结果页时按同一 id 幂等补发。结果页离开/异步回调注意 `mounted`。
3. `lib/features/rewards/rewards_page.dart`（新增）、`lib/app/router.dart`、`lib/features/learning_path/learning_path_page.dart`：首页进度旁增加带 tooltip 的收藏图标按钮（不挤压小屏标题），进入可返回的收藏册。以单元顺序列出 14 种徽章、主题名称和次数；未获得的显示锁定态。使用 Flutter 内置图标与现有绿色、金色、蓝色等配色组合制作可辨认的主题图案；不引入线上图片依赖或外部素材。收藏列表可滚动并处理小屏文字换行。
4. `lib/main.dart`、`lib/app/providers.dart`：启动时打开奖励 box 并注入按账号作用域的奖励仓库；如需要刷新收藏页，通过专用 revision provider 或监听 box 变化，避免依赖课程进度的非响应式读数。
5. `lib/core/services/backup_service.dart`、`test/backup_service_test.dart`：导出 JSON 升为 version=2，新增仅当前账号的奖励尝试数组（attemptId、unitId），保留原 user/progress 字段；导入同时接受 v1（无奖励）和 v2（有奖励）。先验证奖励列表的字段类型、单元 id、重复 attemptId 等，再写入；按 id 合并导入，重复导入不能重复累计，其他账号奖励不得导出。旧版 v1 备份仍能恢复账号及进度。
6. `test/reward_repository_test.dart`、相关 widget 测试：覆盖每次真实通过加一次、重学通过再加一次、失败/跳关不发、同尝试幂等、跨账号隔离、14 单元映射、重启后保留及旧备份兼容。更新 `lib/core/constants.dart`、`pubspec.yaml` 至下一版本（建议 0.6.8+14）；确认本地分发服务器仍使用此前局域网地址后，将 `.trae/gen_qr.py` 指向新文件名 `v068.apk`。

## Assumptions & Decisions

- 将用户选择的「收藏奖励」落实为 14 种单元主题徽章，而非随机抽卡；每次达标获得对应单元徽章 `+1`，因此重复通关仍有明确反馈。先不做稀有度、抽奖和消费系统。
- 只有真实答题且本次正确率达到 70% 才发放；无论该课以前是否完成，重学达标均可获得。跳关、未达标、单纯打开结果页均不发奖。
- 旧版本已有通关进度不追溯补发；升级后第一次实际通关才增加次数。旧账号与游客都能使用收藏，游客数据仍仅留本机，备份规则与现有账号备份一致。
- 徽章主题与本地课程单元 id 对应，不修改课程 JSON 或当前 `LessonProgressAdapter`；奖励独立存储以减少升级风险。
- 不要求联网；视觉动效遵循系统减少动画偏好，避免长时间阻塞返回按钮。
