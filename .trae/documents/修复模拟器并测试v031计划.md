# 修复模拟器并测试 v0.3.1 计划

## Context（背景）

用户要求"模拟器打开测试"，但模拟器启动报 `No initial system image for this configuration!`。排查确认：`D:\fv_sdk\android-sdk\system-images\android-36\google_apis\x86_64\` 缺 `system.img`（当初复制不完整，只有 vendor.img/ramdisk.img/kernel-ranchu 等）。本计划补齐镜像、启动模拟器、安装 v0.3.1 APK 验证登录/游客横幅/答题全流程。

## 现状关键事实（已只读核实）

- 缺 `system.img`；`source.properties` Pkg.Revision=7。
- 目标包：`x86_64-36_r07.zip`（1,895,447,397 字节 ≈1.9GB，revision 7 匹配）。
- 下载源（已实测）：腾讯镜像 `https://mirrors.cloud.tencent.com/AndroidSDK/sys-img/google_apis/x86_64-36_r07.zip` 200 且长度完全匹配（首选）；dl.google.com 同路径也 200（备用）。阿里云无此包。
- D 盘空闲 25.87GB，足够。
- 沙箱写限制：`D:\fv_sdk` 不在可写白名单，但其 junction 实体 `d:\workspace\github_code\地球村\.trae\sdk` 在项目目录内可写 → **下载/解压一律走项目路径** `.trae\sdk\android-sdk\...`。
- 模拟器启动（记忆验证过）：`ANDROID_AVD_HOME=C:\Users\vincent\AppData\Local\Temp\avd`，参数 `-no-window -no-audio -no-boot-anim -gpu swiftshader_indirect -accel on -memory 3072 -no-snapshot -no-metrics`（WHPX）。
- 包名 `com.example.english_village`，MainActivity。待测 APK：`.trae\v031.apk`。

## 实施步骤

1. **下载镜像**（后台，约 1.9GB）：
   `Invoke-WebRequest 'https://mirrors.cloud.tencent.com/AndroidSDK/sys-img/google_apis/x86_64-36_r07.zip' -OutFile 'd:\workspace\github_code\地球村\.trae\x86_64-36_r07.zip'`
   失败则换 dl.google.com 同路径。下载后校验长度 = 1895447397。
2. **解压合并**：用 `tar -xf` 解压到 `.trae\sdk\android-sdk\system-images\android-36\google_apis\`（zip 顶层为 `x86_64/`，与现有目录合并覆盖）。验证 `system.img` 存在且 >1GB。删除临时 zip 释放空间。
3. **启动模拟器**（后台）：设 `ANDROID_AVD_HOME`、`ANDROID_SDK_ROOT=D:\fv_sdk\android-sdk`，运行 `D:\fv_sdk\android-sdk\emulator\emulator.exe -avd test_avd <上述参数>`。
4. **等待启动完成**：`adb wait-for-device` 后轮询 `adb shell getprop sys.boot_completed` 直到 =1（上限约 5 分钟）。
5. **安装并启动 App**：`adb install -r .trae\v031.apk`；`adb shell am start -n com.example.english_village/.MainActivity`。
6. **验证**：
   - `adb logcat -d` 无 FATAL/崩溃；
   - 截屏 `adb shell screencap` + `adb pull` 到 `.trae\screen_v031.png`，确认全新安装首屏为**欢迎页**（大 Logo + 开始学习 + 登录/注册）；
   - `adb shell input tap` 点"开始学习"区域 → 再截屏确认进入首页且出现**游客横幅**。
7. **更新项目记忆**：记录镜像修复方式（腾讯镜像 zip 直下 + 解压合并）替换"可用 sdkmanager 重下"的旧建议。

## 假设与决策

- 直接下载 zip 解压而非 sdkmanager（sdkmanager 默认走 dl.google，历史被阻断风险高；zip 直下可控、可校验）。
- 解压覆盖不影响现有 vendor.img 等（同 revision 7 的完整包，文件一致）。
- 模拟器首装无会话 → 应显示欢迎页，可顺带验证登录功能 UI。
