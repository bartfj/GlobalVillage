# 修改文档：系统语音可见与播放失败提示

日期：2026-10-18

文件：

- `android/app/src/main/AndroidManifest.xml`
- `lib/features/lesson/widgets/listening_choice_widget.dart`
- `lib/features/lesson/widgets/production_exercise_widget.dart`
- `test/audio_failure_test.dart`

## 问题

Android 11 及以上默认看不到其他应用的语音引擎。系统 TTS 因此不可见，朗读会直接失败。失败提示也没有说明需要安装英语语音数据。

## 修改

清单里声明 `TTS_SERVICE` 查询，让系统语音引擎对 App 可见。

听力题和产出题播放失败时提示：「语音播放失败，请安装英语语音数据，并检查媒体音量后重试。」
