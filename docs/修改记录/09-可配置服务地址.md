# 修改文档：可配置服务地址

日期：2026-10-18

文件：

- `lib/data/sources/api_base_url.dart`
- `lib/app/api_base_url_controller.dart`
- `lib/data/sources/settings_store.dart`

## 问题

在线服务地址只能在打包时用 `API_BASE_URL` 写死。临时隧道或换机器后，已安装的 App 无法改地址。

## 修改

`normalizeApiBaseUrl` 整理用户输入：空字符串表示恢复默认；没有写路径时补上 `/v1`；只接受 `http` 和 `https`。非法地址返回空。

设置里保存自定义地址。未配置时仍用编译期 `kApiBaseUrl`。`ApiBaseUrlController` 负责读取和写回。

同一处设置还生成并记住本机 `installId`，供诊断上报区分安装，不随地址清除。

登录页上的地址对话框，以及会打开对话框的 `test/api_base_url_test.dart`，要等应用启动接线之后才接上，见《把新能力接到启动流程》。
