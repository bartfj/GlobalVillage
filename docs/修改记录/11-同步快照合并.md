## 修改

绑定本地账号到在线账号时，按确定规则合并两边的同步快照，不提供手工三方合并界面。

- 进度：两边都保留。同一课都完成时取得分更高的一条；得分相同则取得完成时间较新的一条。
- 奖励：取并集。同一个 `attemptId` 以来源为准。
- 线路：以来源为准；来源没有线路时保留目标。

`SyncApi` 也可以每次读取当前服务地址。管理端触发合并的 HTTP 路由与服务端测试在挂载路由时一起提交。
