# 修改文档：翻译题音标手势测试

日期：2026-10-18

文件：`test/translate_choice_phonetic_test.dart`（新文件）

## 目的

锁定翻译选项按词查音标，避免再退回「整卡长按只查句首词」。

题目使用 `u53l1e1`：题干「我可以和药剂师说话吗？」，正确选项 “Could I speak to the pharmacist?”。音标服务注入本地表，`could` 为 `/kʊd/`，`pharmacist` 为 `/ˈfɑːrməsɪst/`，网络请求固定返回 500。

## 用例

1. 未判定：短按 `pharmacist?` 选中整句，且不出现单词 `pharmacist` 的气泡。随后长按 `pharmacist?`，气泡词是 `pharmacist`，音标是 `/ˈfɑːrməsɪst/`，不是 `could`。
2. 已判定：点按 `pharmacist?` 不触发 `onChanged`，气泡同样是 `pharmacist` 及其音标，不是 `could`。

每个用例结束会关掉音标气泡并释放查询服务。
