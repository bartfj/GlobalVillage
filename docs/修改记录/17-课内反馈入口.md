# 修改文档：课内反馈入口

日期：2026-10-18

文件：

- `lib/features/lesson/lesson_page.dart`

## 修改

课时页和专项练习页的顶栏，在进度数字右侧增加「反馈问题」按钮。点开后使用已有的反馈对话框：说明可以不填，发送时带上这台手机已经记下的错误。

发送结果与首页菜单相同。已发出显示「已发送」；当时没有网络时显示「已保存在手机上，联网后会自动发送」。

## 不变

首页菜单里的反馈入口仍在。反馈仍不记录答错本身，只附带已经记下的异常。
