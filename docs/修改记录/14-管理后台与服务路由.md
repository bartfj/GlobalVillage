## 修改

同一个账号服务增加 `/admin`。未设置 `ADMIN_TOKEN` 时，后台路由不存在，响应也不提示有后台。口令用 Bearer 传递，常量时间比较，不放进 URL 或用户 JWT。

管理员可以列出账号、查看同步快照、停用和恢复、重置密码、删除账号及其云端快照。停用或改密后旧 token 立即失效。手机上的本地进度不删。

这次同时把已经写好的内容下发、诊断上报和同步合并路由挂到 `api.dart`。Postgres 调试端口默认仍是 5432，可用 `POSTGRES_PORT` 改到 5433，避免和本机已有的 Postgres 冲突。`dev-db.sh` 与 `dev-tunnel.sh` 用于本机起库和临时外网隧道。
