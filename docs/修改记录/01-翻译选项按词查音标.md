# 修改文档：翻译选项按词查音标

日期：2026-10-18

文件：`lib/features/lesson/widgets/translate_choice_widget.dart`

## 问题

中译英翻译选择题的英文只出现在选项里。选项原先是一整段 `Text`，整张卡片长按才会查音标，而且只取句首英文词。长按 “Could I speak to the pharmacist?” 只会查出 `Could`，气泡锚在整张卡片上。判定之后卡片不再接收点按，单词也打不开音标。整句虚线下划线看起来像每个词都能点。

## 修改

去掉 `_OptionCard._showPhonetic` 和卡片上的 `onLongPress`。英文选项改为 `TappablePhoneticText`，中文选项仍是普通 `Text`。

- 未判定（`enabled == true`）：`lookupOnLongPress: true`。短按选中该选项，长按被按住的那个词弹出音标。
- 已判定（`enabled == false`）：改为点按该词弹出音标。此时卡片的选中手势已关闭。

手势与连线题 `match_pairs_widget.dart` 相同。音标气泡仍用现有的 `showPhoneticBubbleForBox`，不新做词典页。不再依赖 `AppColors`，已去掉 `app/theme.dart` 引用。

## 不变

中文题干仍是普通文本。英文题干本来就是按词可点的 `TappablePhoneticText`。非英文课程的 `LanguageExerciseWidget` 未接这套音标。
