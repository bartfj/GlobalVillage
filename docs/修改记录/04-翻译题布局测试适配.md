# 修改文档：翻译题布局测试适配

日期：2026-10-18

文件：`test/lesson_design_test.dart`

## 原因

英文选项和底部英文答案改成按词渲染后，整句不再是一个 `Text`。原测试点按 `Stand up, please.`、`Listen, please.`，并断言能找到整句 `exercise.answer`，会找不到控件。`TappablePhoneticText` 是 `ConsumerWidget`，测试树需要 `ProviderScope`。

## 修改

- 两个用到翻译选项或底部答案的用例包上 `ProviderScope`。
- 未判定时改为点按单词 `Stand`，仍期望选中整句 `Stand up, please.`。
- 判定后改为点按选项字母 `A`，确认选中项不变。点字母是为了测卡片已锁定，不打开音标气泡。
- 底部答案改为断言存在 `TappablePhoneticText`，且其 `text` 等于 `Sit down, please.`。「继续」仍会触发回调。

## 不变

窄屏尺寸、答对答错图标、以及「检查」按钮在没有答案时保持禁用，这些断言未改。
