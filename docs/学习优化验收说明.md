# 学习优化验收说明

## 已实现范围

新增64课的内容台账、指定填空目标、部分干扰项、输入翻译多答案，以及本地错题复习、单元复习、对话应用和分模式学习统计。不增加普通课数，不变更已有课程ID与通关奖励规则。

## 人工验证清单

1. 在Android设备上进入听力选择、听音组句、听写与跟读，验证媒体音量、重复播放和英语语音包。
2. 临时使题目MP3不可用，验证系统TTS回退；再使TTS不可用，确认显示播放失败提示，恢复后可重试。文件头校验不代表可完整解码或逐字一致。
3. 正常课程首次答错后退出，在“复习与学习记录”查看任务；完成复习后确认下一复习日期变化，旧课程成绩不被补分。
4. 完成一单元，分别进入单元8题复习和对话3题应用，确认完成后返回复习页，不发徽章或解锁课程。
5. 切换账号，确认错题与事件隔离；导出内容只包含本地记录，无输入答案原文；清除后普通课成绩与奖励仍在。
6. 以新增教学台账逐课审查生词、句型、自然译文与目标词；标记人工已审课，不能把自动“新词候选”直接当成已校准词表。

## 试学分析

正常课、错题、单元与对话模式分别统计。输入题耗时长不能直接解释为语言困难，需结合打字熟练度、播放失败和退出事件。数据只支持发现待调查问题，不直接映射CEFR等级。

建议先观察每课首次正确率、不同题型平均耗时、重试比例和开始后未结束的事件。只有真实样本积累后，再决定降低生词负荷、调整题型、增补等价答案或改变复习间隔；本轮不伪造试学数据或自动改难度。
