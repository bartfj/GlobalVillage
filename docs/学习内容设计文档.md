## 2. 学习目标与用户

### 2.1 目标用户

零基础课程面向缺少英语学习基础、需要中文支持与短句训练的学习者。初级课程面向已认识基本词句、希望在日常生活和简单公共事务中表达需求的学习者。

中级课程面向具有初级词句基础的学习者，以B1能力为设计目标，训练连贯叙述、解释理由、比较方案、委婉协商、工作沟通和信息判断。当前仍为受控练习，不宣称通关达到B1，不包含开放写作评分或自由对话测评。课程可直接切换进入，不新增初级通关门槛。

当前应用未实施年龄分层或标准化语言等级测评。课程名称不能直接等同于 CEFR 等级；建议后续通过词汇、句法和真实任务测评验证难度定位。农场、学校、泳池等主题偏生活启蒙，银行、职场、住房等主题偏成人生活，内容审核应注意两类受众差异。

### 2.2 能力目标

| 能力 | 零基础目标 | 初级目标 |
|---|---|---|
| 词义理解 | 识别常见物品、动作、数量与基本礼貌表达 | 理解场景中常见请求、说明与回应 |
| 阅读 | 借助中文理解简短句子 | 理解简单通知、问题与事务性短句 |
| 听力 | 将清晰短句与词义、词序对应 | 从短句中获取需求、时间、地点和行动信息 |
| 书面表达 | 从词块重组过渡到受控短句输入 | 根据中文提示写出已学表达 |
| 口语 | 模仿基本发音与句子 | 跟读场景表达，为简单交流建立句式储备 |
| 场景迁移 | 在熟悉生活场景中复用表达 | 在服务、旅行与协作场景中表达和回应 |

这些是内容设计目标。当前主要训练受控表达，尚不能凭课程通关推断自由对话、开放写作或综合语言能力。

## 4. 课程组织与递进

### 4.1 现有主题组织

零基础内容从字母、数字、颜色、课堂用语延伸到身体、家庭、食物、日常生活，再进入社区活动和简单故事。初级内容从基本交际延伸到计划、比较、经历、建议，随后增加职场、文化、公共服务和信息核实。

主题覆盖较广，但当前缺少机器可读的词汇、语法、先修与难度标签。主题顺序不保证严格的句法递进。例如零基础后段已经出现过去时、被动表达和带从句的句子，不能仅依据课程名称认定这些都是基础短句。

### 4.2 建议的学习阶段

以下分组用于内容审校和后续规划，不改变现有单元顺序或解锁逻辑。

| 课程 | 单元范围 | 设计重点 |
|---|---|---|
| 零基础 | 1–4 | 字母与声音意识、数字、颜色、基本课堂请求 |
| 零基础 | 5–16 | 常见词汇、简单描述、请求与生活表达 |
| 零基础 | 17–34 | 扩展表达、物品描述、习惯与社区任务 |
| 零基础 | 35–42 | 情境应用、行动顺序、初步故事理解 |
| 初级 | 1–16 | 基本交际与常见生活场景 |
| 初级 | 17–34 | 计划、比较、经历、建议、观点与解决问题 |
| 初级 | 35–44 | 职场、住房、数字生活、文化与综合表达 |
| 初级 | 45–52 | 公共事务、核实信息、预算、协作与经历总结 |

### 4.3 每单元四课的建议职责

1. 第一课：引入场景与核心词句，优先使用词块和听音组句。
2. 第二课：练习基本行动与回应，加入受控输入和听写。
3. 第三课：变换人物、物品或需求，强化理解与表达复用。
4. 第四课：整合单元任务，检验短句输出并衔接对话。

当前并非所有历史单元都遵循这一教学职责；新增内容可按此审校，旧内容应分批优化。

## 5. 单课设计

### 5.1 当前通用九题结构

| 题位 | 常用题型 | 学习作用 |
|---|---|---|
| 1 | 中文选英文 | 建立中文意图与英文表达的映射 |
| 2 | 英文选中文 | 检查英文意义理解 |
| 3 | 中英连线，4 对 | 集中复现本课核心表达 |
| 4 | 词块组句 | 练习句序并建立表达支架 |
| 5 | 词块组句／输入翻译 | 从重组过渡到主动回忆 |
| 6 | 听力选择 | 检查声音与意义的对应 |
| 7 | 听音组句／整句听写 | 检查听音后的词序或完整输出 |
| 8 | 单词填空 | 回忆目标词并复现句型 |
| 9 | 跟读 | 练习句子发音与表达熟悉度 |

零基础前 4 单元第 7 题为听力选择。实际数据应以 JSON 为准，不能将新增生成器的语料选取规则套用于全部历史课程。

### 5.2 新增内容的语料复用

`tool/expand_course_content.dart` 为每课提供 4 对中英句子并派生 9 题。第 1 句用于中文选英文、题位 5 和跟读；第 2 句用于英文选中文和听力选择；第 3 句用于题位 7；第 4 句用于词块和填空；4 句共同组成连线题。

该方案便于保持题目一致，但存在输出覆盖不均和即时重复过多的风险。建议审校时为四句分别指定“认识、理解、输出、迁移”的职责，后续通过跨课复现扩大覆盖，而非仅增加同句题目数量。

### 5.3 建议的单课内容简报

每课先写教学简报，再制作 JSON：

- 场景任务：一句话描述学完能完成的行动，例如“在课堂中理解并发出简单请求”。
- 核心语料：4 对中英表达，语义明确且可用于同一场景。
- 新授内容：列出词汇与句型；建议控制在学习者可承受的范围，而非按题数计算。
- 复现内容：注明来自哪些已学课，避免假设学习者掌握未引入词汇。
- 输出目标：明确本课必须能输入或跟读的表达。
- 资源需求：列出音频 ID、发音难点与对话关联。
- 预期难点：记录容易混淆的意义、词序、拼写或句法。

学习时长目前没有经过用户测量，不设置为已达成指标。可在试学后按输入题耗时、重试次数与退出率调整课长。

## 6. 题型内容规范

### 6.1 选择与连线

- 选择题提供 4 个不同选项且唯一正确；答案必须存在于选项中。
- 干扰项应在已学词句范围内，有合理混淆点，避免靠长度、格式或明显不相关主题猜答案。
- 新增生成器目前使用同课四句作为选项并轮换顺序，尚不是经过教学审校的专门干扰项库。
- 连线题固定 4 对；两侧分别唯一，避免同义项或重复译文产生多种有效配对。
- 连线判分使用规范编码，而非显示顺序；不能手工修改答案编码后忘记同步配对内容。

### 6.2 组句、填空与输入

- 词块组句以完整英文句子为词块来源，目标是句序，不是开放写作。
- 听音组句隐藏原句和中文译文，仅提供声音与词块支架。
- 听写隐藏原句和中文译文，输入完整英文句子。
- 输入翻译提供中文提示，要求复现目标英文表达；支持明确配置的 `acceptedAnswers` 等价答案。
- 填空必须存在一个 `____`，将答案填回后应与完整句子一致。
- 新增生成器按首个匹配小写长度 3–10 的词自动选空位；这只是机械规则，编辑必须检查空位是否真的是教学目标。
- 提示必须约束答案。例如“请坐下。”存在多个自然译法，单答案模式下宜定位为已学句式的受控表达，不能宣传为开放翻译。

### 6.3 跟读与发音

跟读展示目标句并支持发音、录音与识别。当前以识别文本和目标句的相似度评估，组件阈值为 `0.6`；达标后回传目标句给统一判分流程。

这不是音素级发音评分，也不应解释为发音达到 60 分。识别失败、背景噪声和设备差异会影响结果。识别服务不可用时允许降级确认跟读并跳过，该题不计正确分。

## 7. 对话与声音资源

### 7.1 单元对话

- 文件：`assets/dialogues/unit_dialogues.json`。
- 按 unit ID 查找；每组 3 行，speaker 为 `0` 或 `1`，具有英文与中文文本。
- 新增 16 单元采用 `0 → 1 → 0` 三轮交流。
- 通关并成功保存后播放单元对话，再进入庆祝流程；同单元不同课会复用同一组对话。
- 对话应具有“发起意图 → 合理回应 → 跟进或完成”的连贯结构，不应只是三句互不相关的示例句。
- 当前对话属于播放与理解环节，未设置独立理解题或对话能力计分。

### 7.2 音频策略与现状

题目发音优先查找 `assets/audio/listening/{exercise.id}.mp3`，缺失或播放失败时回退系统英语 TTS。TTS 使用 `en-US`，设置语速 `0.45`，实际表现取决于设备引擎与语音包。

当前按听力选择、听音组句、听写和跟读四类题的ID检查：零基础696个、初级816个、中级192个，共1704个题目音频引用；142单元共426个对话音频引用，总计2130项。原有1410项通过大小与MP3文件头检查，本轮新增720项缺少内置MP3，依赖系统英文TTS回退。文件头检查不等于完整解码、音频质量或播放成功率验收。

远端提交 `1b08e74` 已补齐上一轮16单元题目与对话音频，不包含本轮新增48单元。题目音频仍在失败时回退TTS；听力选择、听音组句与听写在服务返回播放失败时显示提示，允许重试。系统返回成功并不保证实际可听，需在真实设备上验证。

建议优先人工试听听写、听音组句和新增单元对话音频，检查句子与录音逐字一致、音量统一、停顿自然，无削波、长静音或背景噪声。离线语音识别模型与发音音频是不同资源，不能互相替代。

## 8. 判分、重试与进阶

### 8.1 当前规则

- 听写忽略全部空格（含全角、不换行空格和零宽空格）。其他文本题忽略大小写、首尾空格、重复空白及末尾 `[.!?,;]`，仍保留词间空格。
- 输入翻译接受显式配置的等价答案；听写除空格外保持规范原句。未收录的缩写、同义表达与内部标点变化不一定被接受。
- 首次答对才计入正确题数。首次答错进入队尾重做，第二次答错后直接前进。
- 重做答对不补回首次正确分；进度表示实际出队完成题数，不是累计答题次数。
- 一课正确率达到 `70%` 即通过。9 题需要至少 7 题首次答对；6/9 不通过。
- 识别降级跳过不计正确，但该题仍包含在初始总题数中。
- 第一课解锁，其余课依次要求前一课完成；两条课程分别按各自顺序判断。
- 保留历史完成状态与较好成绩。存储通过完成记录管理进度，而非词汇或技能熟练度。
- 存在临时跳关入口，可写入完成状态并解锁后续课，但不伪造答题成绩；它是正常正确率门槛之外的例外。

### 8.2 教学解释与后续方向

当前正确率衡量“本次首次作答的表现”，不是完成重试后的掌握率。连线题、单词填空和整句输入各计一题，不能据此比较不同技能的精确水平。

建议未来分开记录首次成绩、纠错完成与技能表现；跨课错题和间隔复习应另行设计，不能将当前队尾重试称为间隔重复系统。对自由表达的支持需先扩展答案模型及测试，而非直接放宽输入文案。

## 9. 内容数据与兼容性

### 9.1 数据模型

层级为 `Course → Unit → Lesson → Exercise`。课程与练习定义位于 `lib/data/models/course.dart`，加载入口为 `lib/data/sources/course_loader.dart`。

| 字段 | 用途与约束 |
|---|---|
| `id` | 稳定身份标识，不因标题修订而重编号 |
| `type` | 9 种题型之一，与枚举名称完全一致 |
| `prompt` | 中文提示、英文题干或任务描述，依据题型解释 |
| `sentence` | 完整英文句子，常用于发音和词块；连线题可为空 |
| `options` | 选择题的四个选项，非选择题通常为空 |
| `answer` | 规范答案；连线题为配对编码；填空为缺失词 |
| `sentenceWithBlank` | 填空句，其他题型可为空 |
| `pairs` | 连线配对数据，旧数据缺省为空列表 |

零基础编号示例：`z_u35`、`z_u35l1`、`z_u35l1e1`。初级编号示例：`u45`、`u45l1`、`u45l1e1`。

### 9.2 兼容要求

学习进度以 lesson ID 关联。已有 ID 不应重用或随意重排；删除课、插入到旧路径中或改变解锁先后需要单独评估。仅改标题通常无需进度迁移，但替换同 ID 的主要教学目标会导致旧完成记录不再代表新内容掌握，需制定兼容策略。

当前没有按每课内容修订号区分历史成绩。新增词汇、语法、技能、先修或多答案字段都是后续模型扩展，不应直接假定运行时已经支持。

## 10. 内容生产与验收

### 10.1 工作流程

1. 明确单元任务、目标用户与先修表达。
2. 编写四课简报、每课核心语料及三轮单元对话。
3. 审校英文自然度、中文准确度与难度，标记需要复现的旧内容。
4. 生成或编辑 JSON，保留旧 ID，审查题型分配与干扰项。
5. 制作音频并按题目 ID 关联；核对对话播放路径。
6. 运行结构校验、自动测试及真实设备试学。
7. 检查最终 APK 中的课程和声音资源，再发布并记录内容变更。

### 10.2 现有工具

| 文件 | 职责 | 注意事项 |
|---|---|---|
| `tool/expand_course_content.dart` | 生成最新新增的 16 单元及对话 | 基线固定为零基础 34、初级 44 单元，不是任意规模扩课工具 |

### 12.3 中文课程设计

中文以普通话生活交际为目标，建议简体汉字为主，入门阶段提供拼音支持。首批共16课、4单元，拆分为两条课程：中文零基础（单元1，拼音与声调）与普通话入门（单元2–4）。下面是主题范围，不是已发布的逐课语料：

| 单元 | 内容重点 | 能力目标 |
|---|---|---|
| 1 拼音与声调入门 | 常见声母、韵母、四声及轻声初识 | 建立字、拼音、声音之间的对应，不宣称16课覆盖全部拼音 |
| 2 问候与自我介绍 | 问候、姓名、身份、礼貌回应 | 用短句介绍自己并回应别人 |
| 3 数字、人物与物品 | 基础数量、人物称呼、常见物品、简单量词 | 理解并表达熟悉的人、物与数量 |
| 4 生活请求 | 简单点餐、购物与基本请求 | 在受控场景中选择、组句和表达需求 |

拼音是教学支架，不默认等同于汉字答案。每道题需明确要求汉字、带声调拼音或其他指定表示，允许的等价答案显式维护。组句使用人工提供的词语或短语块，不按英文空格拆分，也不简单逐字切割所有句子。繁体字、无声调拼音或数字声调是否可接受须按题目目标决定，不能全局放宽。递进的外部依据与扩课标准见 12.3.1–12.3.4。

#### 12.3.1 单元递进依据

对外汉语教学的公开依据主要有四类（来源见末节参考列表）：

| 依据 | 顺序要点 | 性质 |
|---|---|---|
| HSK 一级大纲 | 150 词按主题分组（代词、疑问词、数字、时间、家庭、地点、饮食、物品、动词、形容词、量词、方位）；约 45 个语言点：数字与时间表达、的、基本句序、吗/呢、疑问词、是……的、不/没、二/两、会/能、了、连动句 | 等级标准 |
| 《HSK 标准教程 1》 | 15 课顺序：你好 → 谢谢 → 你叫什么名字 → 她是我的中文老师 → 她的女儿今年 20 岁了 → 我会说汉语 → 今天几号 → 我想喝茶 → 你的儿子在哪儿工作 → 我能坐这儿吗 → 现在几点 → 明天天气怎么样 → 他在学做中国菜呢 → 她买了很多衣服 → 我是坐飞机来的 | 教材课序 |
| 对外汉语语音教学研究 | 语音按“单韵母 → 声母 → 声调”引入；声调教学分“字调 → 变调 → 语调”三阶段；声调难度顺序存在流派（1-4-2-3 或 1-4-3-2，因学习者母语而异），但一致要求最小对立对对比操练；送气/不送气（b/p、d/t、g/k）、zh/ch/sh 与 z/c/s、j/q/x 是欧美学习者主要难点 | 教学研究 |
| 汉字教学实证研究 | 江新（2007）实验表明“认写分流、多认少写”组的识字效果优于认写同步组；Packard（1990）支持拼音先行、汉字延迟引入；Ke（1996）证实认读与产出是两种不同能力 | 实证研究 |

公共结论与按本项目约束（自学、无音频、文本判分、英语解释）的裁决：

1. 拼音先行、汉字随行：拼音先行与认写分流均有实证支持，且本项目没有书写题型，天然是“只认不写”。拼音是答题面，汉字只做识读支架，现有单元排法与此一致。
2. 声调按字调阶段处理：入门期通过声调最小对立对成对呈现（mā/má/mǎ/mà 同单元出现），不按“声调课”孤立讲规则；干扰项优先取声调对立项，尤其二声/三声分辨（欧美学习者公认难点）。
3. 变调只教词汇化结果：三声变调、“一”“不”变调在入门期不讲规则；拼音一律书写本调（nǐ hǎo 不写成 ní hǎo），连读变调仅以注释形式提示。此裁决与梵文“sandhi 只教词汇化结果”（12.4.1）同构。
4. 语法递进以 HSK 一级语言点与教材课序为骨架：是字句 → 吗/呢问句 → 疑问词 → 的 → 不/没 → 数字与时间 → 会/能；了、把字句、连动句推迟到 32 课之后。量词从“个”开始按场景逐个引入，不一次铺开。现有单元 1–4（拼音声调 → 问候与是字句 → 数字与量词“个” → 生活请求“想/要”）与此一致。

#### 12.3.2 语料选择标准

- 词汇以 HSK 一级 150 词为入门公共词汇层，按主题分组编课；超纲词每单元至多 1 个且必须是交际必需（如具体食物名），在含义中标注。
- 数量上限：每单元 8 条语料中新词不超过 8 个、新汉字不超过 12 个（由已学字组成的词不计新词，但计入新组合；人名等专名用字只做整体认读，不计入新汉字上限）；入门句不超过 5 个词。中文无语形变化，不设“新词形”上限，用新汉字数控制识字负荷。
- 声调对立对成对编排：同一音节的不同声调（mā/má/mǎ/mà、shū/shú/shǔ/shù）必须在同单元或相邻单元成对出现；识读与选择题为声调对立项优先。
- 形近字干扰：汉字识读题干扰项优先取形近字（人/入、大/太、木/本、未/末），与梵文“字形易混组”规则（12.4.2）同构。
- 组句词块人工切分：中文没有空格分词，词块必须由语料作者按词语边界人工给出（生成器已如此实现），不允许程序按字切分。
- 拼音书写规范：一律标本调、轻声不标调；ü 在 j/q/x/y 后按规范省略两点书写（ju、qu、xu、yu），输入别名 v→ü 只是键盘便利。

#### 12.3.3 复现与练习设计

- 汉字复现：同一汉字在新词中复现（学 → 学生/学校、人 → 中国人/人们），复现词算新组合不算新字；现有“第 3 课交错、第 4 课综合”机制优先安排含复现汉字的条目。
- 错题进入既有间隔复习机制（当天、1/3/7 天推进），中文错题与英语、梵文按题目 ID 独立追踪。
- 音频题型边界：中文零基础每课第 2 题为听音辨调（播放汉字读音，选出带声调拼音），音频按“已下载缓存 → 内置 mp3 → 系统中文 TTS”顺序获取；课前学习卡的每条核心内容也可单独播放发音。入门课（第 2 单元起）仍禁用听写、跟读与自动口语评分，直到有校验过的中文音频。
- 题型配比：每课识别题与产出题（组句 + 输入）约各半；纯拼音单元允许全部识别题，并以听辨题覆盖声调听辨。
- 判分保持声调严格对立：mā 与 mà 不同答案；声调缺失（ma）不接受；数字声调（ma4）与 v→ü 仅是输入便利，不构成判分放宽。

#### 12.3.4 审校与验收

每条语料的审校检查单：

1. 拼音逐字核对：声母、韵母、声调全部正确；轻声、隔音符（xī’ān 类）按规范书写；汉字与拼音逐字一致。
2. 字词正确：简体字形正确；用词为现代普通话口语；量词搭配正确。
3. 译文与干扰项：英语解释自然且唯一指向目标答案；选择题无多个合理答案；干扰项符合 12.3.2 的声调对立与形近字规则。
4. 组句词块边界经人工确认；新词／新字台账与生成器同步更新。

难度观测沿用 12.4.4 的区间与流程：识别题首答正确率 60–85%、输入题 40–70%；同一单元连续两课重做率超过 50% 视为递进断裂信号。验收流程同梵文五步（生成 → 自动结构校验 → 审校 → 真实设备试学 → 按指标回修），审校者需具备对外汉语教学能力或普通话母语水平；当前 16 课只完成到第 2 步。

### 12.4 梵文课程设计

梵文以初级教学场景中的基础交流和语法为目标，使用天城体与IAST转写对照；生活场景用于语法练习，不将梵文描述为普遍使用的现代日常语言。语料须由具备梵文能力的审校者核对自然性、性数格、动词形式及译文。

| 单元 | 内容重点 | 能力目标 |
|---|---|---|
| 1 元音与长短音 | 独立元音字母 a/ā/i/ī/u/ū/e/o，长短对立 | 识别元音字形与长短差异 |
| 2 辅音与音节 | ka/ma/na/ta/ṭa 及 k 加元音符号拼出 kā/ki/kī | 建立“辅音自带 a、元音符号换音”的拼读规则 |
| 3 单词与问候 | 只用已教字母组成的词（mama、nāma、naṭa 等）及问候 | 拼读已教字母构成的词；namaste 为标注“整体认读”的例外 |
| 4 人称与动作 | ahaṃ/tvam/naṭaḥ 加 paṭh、gacch 的现在时三人称 | 在明确上下文中选择或输入已教人称动词形式 |

按系统课程拆分：单元1–2 组成**梵文零基础**（只学字母与拼读），单元3–4 组成**梵文入门**（词句与人称动词）；切到梵文时默认进入零基础课。

递进遵循**字母依赖原则**：后一单元天城体词只使用前面单元教过的字母与元音符号；含未教字母的词必须标注“整体认读”。送气对比（ka/kha/ga）、卷舌系列和复合辅音（连字）按此原则在后续单元递进引入，不在入门单元一次铺开。中文和梵文每课开始前展示“课前学习卡”（本课核心内容的天城体／拼音、目标表达与解释对照），看完再做题，避免零基础学习者未经任何准备直接答题。递进的外部依据与扩课标准见 12.4.1–12.4.4。

首版优先识读、配对、组句、词形选择与受控输入。每题明确要求天城体还是IAST，只有针对该题维护的等价答案可跨表示接受。判分采用Unicode规范化，使组合字符与预组合字符等价；长短元音、送气、卷舌、鼻音、visarga等区别必须保留，不得通过移除附加符号来判同。连声变化仅在已教授且题目明确允许时接受。

没有可靠且校验过的音频时，不安排依赖声音的听写、辨听或自动口语评分。不能将英文TTS、英语语音识别模型或近似的其他语言语音作为梵文正确发音来源。

#### 12.4.1 单元递进依据

对比四条成熟路线的教学顺序（来源见末节参考列表）：

| 路线 | 顺序要点 | 性质 |
|---|---|---|
| Samskrita Bharati 口语课程（Level 1–3、DLP Pravesha） | 无动词句与自我介绍先行（mama nāma、asti）→ 指示代词 saḥ/sā/tat → 疑问词与场所词 → 格的“用例”随交际需要逐个引入（kena 用、kṛte 为了），系统七格变格推迟到 Level 2；动词从第三人称日常动作开始，现在时 → 命令式 → 将来/过去 | 口语优先 |
| Learn Sanskrit Online 核心课 | 元音长短 → 辅音 → anusvāra/visarga → 音节 → sandhi → 句子 → 名词 → 动词 → 不变词 → 前后缀 → 复合词 → 复习，随后安排“间歇期”转向内容习得；名词按词干族推进（a → ā/ī/ū → i/u → ṛ → 复合元音 → 辅音词干） | 内容习得 |
| 剑桥梵文导论（Ruppel 2017） | 文字 → 声音 → 现在时动词 → a 词干 → 元音变换 → 内部/外部 sandhi 分三步 → i/u 词干 → 辅音词干；人称代词靠后（第 20 章起） | 学术阅读 |
| 博洛尼亚大学 Sanskrit 1 | 音系 → 元音变换 → sandhi → 不变词 → 变格 → 复合词 → 动词系统；要求学习者先具备屈折语“格”概念 | 学术语法 |

公共结论与按本项目约束（自学、无音频、文本判分）的裁决：

1. 文字教学各路线一致：元音先教长短对，辅音按 varṇamālā 分组（ka kha ga gha ṅa / ca 行 / ṭa 行 / ta 行 / pa 行 / 半元音 / 咝音 / ha），元音符号紧跟辅音教学，复合辅音一律后置。现有单元 1–2 与此一致。
2. sandhi 引入时机是主要分歧：学院派在变形前系统讲授，口语派几乎不讲规则。裁决：入门期只教词汇化结果（如 namaste = namaḥ + te 作为注释出现），规则判分推迟到中级规模。
3. 格的教学方式是另一分歧：学院派按词干族全表推进，口语派按用例逐个引入。裁决：采用用例驱动（一次一个用例，术语放括号注释），与“规则滞后于语料”一致；未来教词干族全表时按 a → ā/ī/ū → i/u → 辅音词干顺序。
4. 动词顺序各路线一致：现在时第三人称先行，第一/二人称紧随（现有单元 4 一致）。命令式在口语课中很早（请求、mAstu），适合“生活请求”场景，可在人称掌握后引入；过去时、将来时推迟。
5. 双数、ātmanepada、派生动词、复合词构词法均推迟，不属于入门范围。

#### 12.4.2 语料选择标准

- 具体词优先：实物名词（phala、grāma、jalam）与可见动作动词（√gam 走、√paṭh 读、√likh 写、√khād 吃、√nī 引导、√dā 给）构成入门公共词汇层；抽象概念只用已学词组合表达，不单独新授。此原则来自 Samskrita Bharati 的“具体词演示、抽象词联想”教学法，在自学 App 中落实为“具体词配中文释义、抽象词不出现在 8 条核心语料”。
- 数量上限：每单元 8 条语料中新词不超过 6 个、新词形不超过 4 个（由已学词组合的句子不计新词）；新授与复现逐条写入台账。入门句不超过 4 个词，每句只含一个未复习过的语法点。现有单元 3 有 7 个新词、单元 4 有 6 个新动词形式，略超上限，下次语料修订时压缩或拆分。
- 最小对立对成对编排：长短元音（a/ā、i/ī、u/ū）、送气（ka/kha、ta/tha）、卷舌（ta/ṭa、na/ṇa）必须同单元成对出现，选择题干扰项优先取对立项。天城体识读题的干扰项优先取字形易混组（ख/र/व、ट/ठ/ढ/द、प/फ/य/ष、भ/म、व/ब）。
- 整体认读例外：含未教字母的词每单元至多 1 个，必须在含义中标注“整体认读”。其 IAST 形式可正常作为输入答案（输入面是 IAST，始终可打字），标注仅表示天城体不要求拼读。
- 问候与固定表达（namaste 类）作为整体语块教学，不拆解语法。

#### 12.4.3 复现与练习设计

- 词形变换复现：同一词干跨单元以新词形复现（如 naṭa → naṭaḥ/naṭam，ahaṃ → mama）。复现词形不算新词，但计入新词形上限；现有“第 3 课交错、第 4 课综合”机制优先安排词形变换版本。
- 错题进入既有间隔复习（当天、1/3/7 天推进）的机制不变；梵文错题按题目 ID 独立追踪，与英语、中文互不干扰。
- 无音频安全题型：识读选择（天城体 → IAST）、意义选择（解释语 → IAST）、组句、受控输入。禁用听力选择、听音组句、听写、跟读，直到有校验过的梵文音频；当前生成器已只产出前三类与输入题。
- 题型配比：每课识别题与产出题（组句 + 输入）约各半；纯字母单元允许全部识别题。
- 判分保持严格对立：长短元音、送气、卷舌、鼻音、visarga 差异全部保留；ASCII 别名（aa → ā 等）只是输入便利，不构成判分放宽。

#### 12.4.4 审校与验收

每条语料的审校检查单：

1. 字母依赖审计：天城体词的字母与元音符号均在前面单元教过，或已标注整体认读（现有自动测试覆盖）。
2. 形态正确：性数格、人称、时态形式经具备梵文能力的审校者核对；IAST 与天城体逐字符一致（NFC 规范化后）。
3. 译文与干扰项：中文解释自然且唯一指向目标答案；选择题无多个合理答案；干扰项符合 12.4.2 的对立项与易混组规则。
4. 新授／复现台账与生成器同步更新。

难度用学习记录的既有数据观测，不预设“学完达到某等级”：

- 分题型首答正确率目标区间：识别题 60–85%，输入题 40–70%；持续超出区间回查语料难度或题序。
- 队尾重做率与第二次错误率：同一单元连续两课超过 50% 视为递进断裂信号，回查字母依赖与新词上限。
- 错题间隔复习的解决率用于校准复现间隔。

验收流程：语料生成 → 自动结构校验（含字母依赖测试）→ 具备梵文能力者教学审校 → 真实设备试学并记录 → 按观测指标回修。当前 16 课语料为初稿，尚未完成第 3、4 步。

### 12.6 状态、进度与兼容性

每个账号保存上次实际选择的语言，以及各语言下上次选择的系统课程。新语言首次进入选择其首条课程；英语保留旧课程选择，未存设置时保持现有英语初级默认行为。无效或已移除的选择回退到可用课程，不删除历史学习记录。

切换后复用现有当前课定位规则，按所选课程定位下一节可学习课。当前课程目标不变的普通刷新不强制重新定位；全部完成仍提供复习入口。答题页不提供语言切换，须退出返回路径页再切换，避免练习会话关联到错误语言。

英语的课程、单元、课及题目ID保持原值；新语言使用不冲突的ID。成绩和错题需关联正确语言与课程，不清空旧账号数据，不改变已有70%通关与奖励规则。成绩与错题按语言筛选；树木等奖励是否按语言展示或保持账号全局累计需在实现前确认，不擅自迁移或重算。

### 12.7 实现边界与验收

当前 `CourseTrack` 仅表达英语等级。实现时需要区分学习语言与具体课程，沿用现有加载、课程仓库和路径页；不能仅在枚举追加中文、梵文后继续使用英语专用逻辑。课程资源应能表达目标语言、解释语言、转写支架及明确词块；旧英语JSON缺省值须兼容现有行为。

发音服务按目标语言选择语音，检测支持情况与失败反馈。中文需要实际验证普通话语音与声调，梵文音频另行选型、制作和审校。字体须覆盖天城体、连字塑形与IAST附加符号，并验证真实设备渲染。英文音标查询、英文识别和英文判分仅用于英语，不默认作用于新语言。

实施前确认试点规模、文字体系、教学解释语言、奖励展示范围和音频方案。首轮不包括全量英文界面、经典阅读、开放写作评分、梵文自动口语评分或未经确认的大规模扩课。

验收至少覆盖：

1. 顶部与侧栏切换结果一致；取消面板不切换；加载失败不丢失原选择。
2. 三种语言仅显示可用课程与已实现专项；具体课程标题与继续学习目标一致。
3. 切换语言、切换账号和重启后恢复正确选择；旧英语账号进度及成绩不变。
4. 中文词块组句输出正确，拼音支架不泄露听力答案，汉字与拼音判分要求明确。
5. 梵文天城体与IAST在窄屏、大字体、真实设备中可读；Unicode规范化保留有意义的发音差别。
6. 缺失音频、缺少语音包、播放失败及退出练习均有确定行为；无可靠音频的梵文内容不出现听写或评分入口。
7. 新语言复习与学习记录正确隔离，英语现有课程、专项、进度和奖励回归测试通过。
8. 每课语料、译文、目标词与答案审校留有记录；未完成专业审校或真实试听的内容如实标记，不宣称达到语言等级。

### 12.8 本轮试点实施状态（2026-10-12）

新增中文、梵文各4单元16课，每课9题，合计新增288题；全应用600课5400道普通练习题。内容采用选择、人工词块组句和受控输入三种题型，其他英语题型及题库保持不变。中文课程英语解释，首单元要求带声调拼音，其余要求简体汉字；梵文要求IAST输入，选择题提供天城体识读支架，不将两种表示默认互判等价。

中文词块不按英文空格拆分，重组时不插入空格；梵文使用明确词块并按空格重组。新语言答案使用NFC规范化并保留声调、长短音、卷舌、鼻音与大小写差异；允许前后空白及重复空格规范化，不继承英文的小写化和去末尾标点。英文答案规则保持兼容。

课程入口采用“学习语言 → 系统课程”，顶部和侧栏共用选择面板；仅点击具体课程才持久化并切换。取消面板不改变课程，保存失败显示可重试错误。按账号保留各语言最后课程及当前课程；旧英语设置和默认初级行为不变。中文和梵文不显示英语专项，新语言也不能从专项路由进入英语练习。

新增题目不调用英文音标查询、TTS或英语ASR，不配置听写、辨听、跟读和自动口语评分。字体内置Noto Sans Devanagari，并附SIL Open Font License；当前提供文字支架不代表音频或发音能力已完成。真实设备天城体塑形、IAST显示、大字体布局以及专业梵文语法与中文教学审校仍待验收。

输入体验（2026-10-12 补充）：普通手机键盘打不出 IAST 长音符号与拼音声调，输入题在输入框下方提供特殊字符条（梵文 13 个 IAST 字符、拼音 24 个声调字母），点按插入光标处；判分同时兼容普通键盘打法——梵文 aa/ii/uu→ā/ī/ū、大写 R T D N S M H→ṛ ṭ ḍ ṇ ṣ ṃ ḥ、sh→ś，拼音数字声调 ma4→mà、v→ü。兼容展开不改变严格性：短音 a 仍不等于 ā，ta 仍不等于卷舌 ṭa，ma 仍不等于 mǎ。

零基础入门修复（2026-10-14 补充）：试学发现梵文原语料递进断裂——单元 1、2 只教孤立字母，单元 3 直接出现含未教字母、复合辅音与元音符号的 नमस्ते，学习者无任何准备无法入手。本轮重排梵文全部 4 单元语料：单元 1 保留 8 个独立元音（ṛ 延后，补 o）；单元 2 改为辅音与音节拼读（ka/kā/ki/kī 建立元音符号规则，ma/na/ta/ṭa）；单元 3 的词全部只用已教字母（mama、nāma、āma、kāka、naṭa、maṭa），namaste 保留为标注“整体认读”的问候词；单元 4 改为人称与动作（ahaṃ/tvam/naṭaḥ 加 paṭh、gacch 现在时三人称），名词性别与格形式延后到字母体系扩展之后。同时中文、梵文课程新增课前学习卡：每课开始前列出本课核心内容（识读支架、目标表达、解释对照），点击“开始练习”才进入答题；英语课程流程不变。语料仍为初稿，专业梵文教学审校待完成。
