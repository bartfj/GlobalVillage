# 中文与梵文课程台账

中文、梵文各分两条系统课程：零基础课只含拼音/字母单元，入门课承接词句与使用场景。每单元8条核心语料交错复现。中文英语解释，梵文中文解释。梵文题目要求IAST输入，天城体仅作识读支架。无听力、跟读或口语评分。梵文单元间保持字母依赖：后单元天城体词只使用已教字母与元音符号，例外词（namaste）标注整体认读。语料为初稿，专业教学审校、逐句发音及真实设备字体验收待完成。
