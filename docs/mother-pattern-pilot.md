# 初级母句型试点

六节初级英语课在原课程前增加框架讲解，通关且成绩及奖励保存成功后提供可跳过的加练。复习页可直接进入已完成试点课，旧通关记录不生成训练表现。主课题目、ID、70% 门槛、成绩与奖励规则保持原样。

每轮学习为 2 道完整句块拼句、2 道中文提示输入和 2 道场景输入。输入提交前不显示范句或播放答案；主动提示会揭示句型及范句，并单独计数。答案以受控等价答案表判定，大小写、常见标点、弯直引号可规范化；不使用模糊相似度，不把跟读表现当作自由表达能力。

## 内容审校

| 课时 | 框架 | 内容与搭配约束 |
|---|---|---|
| u1l2 | My name is … | 李明、Lucy、Tom、Amy；支持 My name's …，姓名前不加 I/am，情境明确指定扮演的姓名 |
| u4l1 | I like … | 苹果、香蕉、梨、西瓜；泛指喜好的可数水果使用复数 |
| u4l3 | I want … | some water/milk/juice、an apple；区分不可数饮料与一个水果 |
| u4l4 | I would like … | a hamburger/salad/sandwich、some water；支持 I'd like 和句尾 please，保持礼貌目标框架 |
| u9l1 | How much is …? | this shirt/bag/book/apple；本轮仅单数 is，保留 this 指示信息 |
| u9l2 | I need … | some milk/eggs/bread、a shopping bag；轮换另含苹果、水和牛奶鸡蛋组合 |

已按中文任务、英文语法、数量、搭配和先修词汇进行代码与内容审查。词汇来源由自动测试核对对应课及此前课的原句、连线词对。每个句型 3 条范句、6 道学习题和至少 4 道额外场景轮换题。人工教学复核与真人试学另见下面待验项目。

## 本机记录

使用现有 learning_records Hive 盒，外层按账号，内部按课程、稳定句型 ID、内容版本隔离。学习成功要求 4 道回忆及场景题全部首次无提示答对：成功安排次日，否则当天。复习每轮抽 2 道场景题，成功依次推进 3、7、14 天并保持 14 天；错误或提示重置当天。按本地日历日期筛选今日任务，最多 6 个，按最早到期排序。

同轮纠错不增加首次正确数；重复保存同一 sessionId 不推进间隔或轮换。读题不推进游标，完整复习保存才轮换。再次学习成功保留已有复习安排，失败重置当天。训练只写独立记录，不重复奖励。导出与清除包含母句型状态；本版不扩展云同步或账号备份。

## 内容与音频维护

`tool/generate_pattern_pilot.dart` 为非破坏性试点注入工具：默认保留既有 patternTraining，包括人工修订版本；`--refresh` 才重建六课试点字段。扩课工具 generateExpansion(write: false) 的重复生成测试确认保留这六课元数据。

新增 78 个内置 MP3 沿用 `assets/audio/listening/<exerciseId>.mp3` 和 TtsService。录音由 Microsoft Zira Desktop en-US 生成 22050 Hz、单声道、16-bit PCM，再用 LAME 96kbps 编码。修改句子后须先运行 `tools/generate_pattern_wav.ps1`，再运行 `tools/generate_pattern_audio.py --wav-directory .trae/tmp/pattern-wav`。WAV 和 MP3 清单均保存句子 SHA-256；转换和 `--check` 会拒绝过期音频。可选在线生成器需要 edge-tts；离线播放不需要该依赖。
