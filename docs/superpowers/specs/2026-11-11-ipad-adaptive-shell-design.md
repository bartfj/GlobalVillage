# iPad / 宽屏自适应壳设计

日期：2026-11-11  
状态：已确认

## 目标

地球村目前是 iPhone/iPad 通用包，但界面按手机写死，大屏会被拉满。要做完整平板体验：宽度够时左侧导航轨 + 右侧加宽居中内容；宽度不够时保持现有手机布局。覆盖所有可进入页面，不单独出 iPad 包。

## 决策摘要

| 项 | 选择 |
|----|------|
| 适配程度 | 完整平板布局（非仅限宽） |
| 覆盖范围 | 全部可进入页面 |
| 触发方式 | 按可用宽度自动切换（横竖屏、分屏都适用） |
| 主结构 | 导航轨 + 内容区 |
| 内容宽度 | 加宽居中（约 780） |
| 做题时导航轨 | 隐藏（课程 / 专项题面 / 结果页） |
| 导航轨入口 | 现有可进页尽量挂上 |
| 实现方案 | `ShellRoute` 宽屏壳 + 内容柱；各页少改 |

## 非目标

- 不做独立 iPad App / 独立 Bundle ID
- 不做路径页主从双栏（左列表右详情）
- 不改课程数据、同步、账号、判题逻辑
- 不要求 Android 平板单独视觉设计，但同一套宽度断点可复用

## 架构

### 断点

- 以壳的可用宽度为准：`>= 900` 显示导航轨；`< 900` 走现有手机布局
- 旋转或分屏跨过断点时即时切换，不重置当前路由、不丢页面状态

### 路由壳

用 `go_router` 的 `ShellRoute` 增加 `AppAdaptiveShell`：

**进壳（宽屏可显示导航轨）**

- `/` 学习路径
- `/practice/:skill` 技能练习章节地图
- `/sanskrit-audio` 梵文听读
- `/completed` 已完成
- `/review` 复习
- `/badges`（`/rewards` 仍重定向到此）徽章
- `/tree` 梭梭树
- `/account` 账号

**不进壳（始终无导航轨，专注或认证）**

- `/welcome`、`/login`、`/register`
- `/lesson/:lessonId`
- `/lesson/:lessonId/result`
- `/practice/:skill/:chapterId`

认证重定向、梵文听读语言门禁、专项语言过滤保持现有 `redirect` 逻辑。

### 导航轨内容

有会话且宽度达标时显示。建议项：

| 项 | 路由 / 行为 | 可见条件 |
|----|-------------|----------|
| 学习路径 | `/` | 始终 |
| 技能练习 | `SkillPracticeKind.forLanguage(当前语言).first` → `/practice/:skill` | `forLanguage` 非空 |
| 梵文听读 | `/sanskrit-audio` | 当前轨道为梵文 |
| 已完成 | `/completed` | 始终 |
| 复习 | `/review` | 始终 |
| 徽章 | `/badges` | 始终 |
| 梭梭树 | `/tree` | 始终 |
| 账号 | `/account` | 始终 |

选中态按当前 `matchedLocation`（及前缀，如 `/practice/...`）高亮。专项入口若无可用技能则隐藏该项，不指向错误语言。

### 内容柱

抽出共享组件（例如 `AdaptiveContentColumn`），供壳内 child、认证页、专注页复用：

- 宽屏时水平居中，最大宽度约 **780**
- 窄屏时直接返回 child，不加额外约束
- 页面原有内边距大体保留，避免再叠一层过大 padding

壳负责「导航轨 + 可选地包一层内容柱」；不进壳的认证页 / 专注页自行包同一内容柱，保证限宽规则一致。

## 各页适配

### 学习路径

- 蛇形关卡偏移按**内容柱宽度**计算，不按整屏 iPad 宽度
- 宽屏下 AppBar 徽章快捷入口可移除（导航轨已有）；单元目录等页内操作保留
- 宽屏下 `MainMenuDrawer` 隐藏与导航轨重复的页面跳转（专项、听读、已完成、复习、徽章、梭梭树、账号等），保留备份恢复、反馈、关于、界面语言、服务地址、登录/退出等设置类入口；窄屏抽屉保持现状

### 壳内其它页

- 章节地图、梵文听读、已完成、复习、徽章、梭梭树、账号：包进内容柱
- 网格（如梵文听读）列数随内容柱宽度变化

### 认证页

- 不显示导航轨
- 宽屏时表单/主内容限宽居中

### 专注页

- 课程、专项题面、结果页：无导航轨 + 内容柱限宽
- 返回、进度、检查等交互保持手机节奏

## 组件与文件（预期）

- `lib/app/adaptive/adaptive_breakpoints.dart`：`kAdaptiveRailMinWidth = 900`、`kAdaptiveContentMaxWidth = 780`
- `lib/app/adaptive/adaptive_content_column.dart`：共享限宽居中组件
- `lib/app/adaptive/app_adaptive_shell.dart`：宽屏壳与导航轨
- `lib/app/router.dart`：`ShellRoute` 分组；专注/认证路由留在壳外并自行包内容柱
- 页面微调：`learning_path_page.dart`（偏移/AppBar）、`main_menu_drawer.dart`（宽屏隐藏重复跳转）、网格页列宽计算

不引入新的状态管理库；选中语言/专项仍读现有 Riverpod providers。

## 边界情况

- 未登录：只进欢迎/登录/注册，无导航轨
- 游客：与现网一致，可进壳内学习页；导航轨仍可用
- 梵文听读、专项入口随当前语言显隐；语言切换后轨上项与 `redirect` 一致
- 宽屏 ↔ 窄屏切换不强制 `go`，只改变壳的 chrome

## 测试与验收

### 测试

- Widget：宽度 390 → 无导航轨；宽度 1024 → 有导航轨，内容最大宽度受内容柱约束
- 路由：进入 lesson / practice chapter / result 无导航轨；返回 `/` 后恢复
- 回归：窄屏路径、抽屉、认证 redirect 相关现有测试仍通过

### 验收

- iPad（或宽屏模拟器）宽度达标：导航轨 + 加宽居中
- 做题页无导航轨，内容不拉满整屏
- iPhone / 窄屏观感与现在一致

## 实现顺序（供计划拆分）

1. 断点常量 + 内容柱组件 + 壳骨架
2. `ShellRoute` 接入与导航轨入口/显隐
3. 学习路径与抽屉/AppBar 收敛
4. 壳内其余页与网格列宽
5. 专注页内容柱
6. Widget / 路由测试与手动验收
