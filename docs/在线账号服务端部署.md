# 在线账号服务端部署

> 覆盖：**本地测试** + **国内 VPS 生产**（Docker Compose + Caddy HTTPS）。  
> 对应代码目录：[`server/`](../server/)  
> 设计说明：[`在线账号功能设计.md`](./在线账号功能设计.md)

## 1. 架构与环境变量

```text
客户端 App  --HTTPS-->  Caddy(:443)  -->  gv-api(:8787)  -->  Postgres
```

| 变量 | 本地 | 生产 | 说明 |
|------|------|------|------|
| `PORT` | `8787` | `8787`（容器内） | API 监听端口 |
| `JWT_SECRET` | 可用短串 | **必填强随机串** | 为空则用开发默认值（禁止生产） |
| `DATABASE_URL` | 可选 | **必填** | 例见下文；空或 `STORAGE=memory` → 内存库（重启丢数据） |
| `STORAGE` | `memory` 可选 | **不要设 memory** | 强制内存模式 |

`DATABASE_URL` 示例：

```text
postgres://gv:gvsecret@postgres:5432/globalvillage?sslmode=disable
```

- Compose 内网可用 `sslmode=disable`  
- 外部托管库建议 `sslmode=require`

客户端 API 基址（[`lib/data/sources/cloud_auth_api.dart`](../lib/data/sources/cloud_auth_api.dart)）：

```bash
# 默认 http://localhost:8787/v1
flutter run --dart-define=API_BASE_URL=http://127.0.0.1:8787/v1
# 生产包
flutter build apk --release --dart-define=API_BASE_URL=https://你的域名/v1
```

真机调试勿用 `localhost`，改为电脑局域网 IP，例如 `http://192.168.31.78:8787/v1`。Android 模拟器可用 `http://10.0.2.2:8787/v1`。

主要接口：

| 方法 | 路径 |
|------|------|
| GET | `/v1/health`（探活，无鉴权） |
| POST | `/v1/auth/register` / `login` / `refresh` / `logout` |
| GET/PUT | `/v1/sync`（Bearer access token） |

## 2. 本地测试

### 2.1 最快：内存模式（无需 Docker / Postgres）

要求：本机已安装 Dart SDK（与 [`server/pubspec.yaml`](../server/pubspec.yaml) 的 SDK 约束匹配）。

```bash
cd server
dart pub get
JWT_SECRET=dev-local PORT=8787 STORAGE=memory dart run bin/server.dart
```

看到类似：

```text
在线账号服务已启动: http://0.0.0.0:8787/v1
```

冒烟：

```bash
curl -s http://127.0.0.1:8787/v1/health
# 若尚无 health：直接注册
curl -s -X POST http://127.0.0.1:8787/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"test@example.com","password":"secret12"}'
```

成功返回账号与 `accessToken` / `refreshToken`。重启进程后账号数据会清空。

跑服务端测试：

```bash
cd server
dart test
```

### 2.2 接近生产：Docker Compose（API + Postgres）

若仓库中尚无下列文件，可先按 §4 自行创建，再执行。

```bash
cd server
cp .env.example .env
# 编辑 .env：至少设置 JWT_SECRET=一串随机字符

docker compose up -d --build
docker compose ps
curl -s http://127.0.0.1:8787/v1/health
```

停止：

```bash
docker compose down
# 连同数据卷删除（慎用）：
# docker compose down -v
```

### 2.3 仅起 Postgres，本机跑 Dart

```bash
cd server
docker compose up -d postgres
export JWT_SECRET=dev-local
export DATABASE_URL='postgres://gv:gvsecret@127.0.0.1:5432/globalvillage?sslmode=disable'
dart run bin/server.dart
```

（将 `.env.example` 中的用户/库名与 `docker-compose.yml` 保持一致。）

## 3. 生产：国内 VPS + Compose + Caddy

### 3.1 准备

1. Ubuntu 22.04+ 云主机，安全组开放 **80 / 443**（不要对公网开放 5432）  
2. 域名 A 记录指向服务器公网 IP  
3. 安装 Docker Engine + Compose 插件  

### 3.2 部署 API

```bash
git clone <本仓库> GlobalVillage
cd GlobalVillage/server
cp .env.example .env
# 生产务必：
# JWT_SECRET=< openssl rand -hex 32 >
# 确认 DATABASE_URL 指向 compose 服务名 postgres

docker compose up -d --build
```

本机验证（在 VPS 上）：

```bash
curl -s http://127.0.0.1:8787/v1/health
```

### 3.3 Caddy HTTPS

将 [`Caddyfile.example`](../server/Caddyfile.example) 拷为 `/etc/caddy/Caddyfile`（或用户目录），把域名改成你的，然后：

```bash
# 示例：系统安装的 Caddy
sudo systemctl reload caddy
```

`Caddyfile` 核心逻辑：

```text
your.domain.com {
    reverse_proxy 127.0.0.1:8787
}
```

确认：

```bash
curl -s https://your.domain.com/v1/health
curl -s -X POST https://your.domain.com/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"prod-check@example.com","password":"secret12"}'
```

### 3.4 App 生产包

```bash
flutter build apk --release \
  --dart-define=API_BASE_URL=https://your.domain.com/v1
```

### 3.5 备份与运维注意

- 定期备份 Postgres 数据卷或 `pg_dump`  
- 轮换 `JWT_SECRET` 会使已有 refresh token 全部失效，用户需重新登录  
- `.env` 不要提交 Git；仓库应忽略 `server/.env`  
- 升级：拉代码后 `docker compose up -d --build`

## 4. 仓库内配置模板

> 下列文件已在 `server/`；此处保留摘要便于对照。

### 4.1 `server/.env.example`

```bash
PORT=8787
JWT_SECRET=change-me-to-a-long-random-string
POSTGRES_USER=gv
POSTGRES_PASSWORD=gvsecret
POSTGRES_DB=globalvillage
DATABASE_URL=postgres://gv:gvsecret@postgres:5432/globalvillage?sslmode=disable
```

### 4.2 `server/docker-compose.yml`

```yaml
services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: ${POSTGRES_USER:-gv}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-gvsecret}
      POSTGRES_DB: ${POSTGRES_DB:-globalvillage}
    volumes:
      - gv_pgdata:/var/lib/postgresql/data
    ports:
      # 仅本地调试时映射；生产可删掉 ports，只走内网
      - "5432:5432"
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER:-gv} -d ${POSTGRES_DB:-globalvillage}"]
      interval: 5s
      timeout: 5s
      retries: 10

  api:
    build: .
    depends_on:
      postgres:
        condition: service_healthy
    environment:
      PORT: ${PORT:-8787}
      JWT_SECRET: ${JWT_SECRET:?set JWT_SECRET in .env}
      DATABASE_URL: ${DATABASE_URL}
    ports:
      - "${PORT:-8787}:${PORT:-8787}"
    restart: unless-stopped

volumes:
  gv_pgdata:
```

生产建议去掉 `postgres.ports` 的宿主机映射。

### 4.3 `server/Dockerfile`

```dockerfile
# 多阶段：编译原生可执行文件
FROM dart:stable AS build
WORKDIR /app
COPY pubspec.* ./
RUN dart pub get
COPY . .
RUN dart pub get --offline
RUN dart compile exe bin/server.dart -o bin/server

FROM debian:bookworm-slim AS runtime
RUN apt-get update \
  && apt-get install -y --no-install-recommends ca-certificates \
  && rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY --from=build /app/bin/server /app/server
ENV PORT=8787
EXPOSE 8787
CMD ["/app/server"]
```

### 4.4 `server/Caddyfile.example`

```text
# 将 your.domain.com 换成真实域名；DNS A 记录指向本机
your.domain.com {
	encode gzip
	reverse_proxy 127.0.0.1:8787
}
```

## 5. 故障排查

| 现象 | 排查 |
|------|------|
| App 提示网络/登录失败 | 确认 `API_BASE_URL` 含 `/v1`；真机是否通局域网；生产是否 HTTPS |
| 容器起不来 | `docker compose logs api`；`JWT_SECRET` 是否已设 |
| 连不上库 | `DATABASE_URL` 主机名在 Compose 内应为 `postgres`；密码与 `POSTGRES_*` 一致 |
| 重启丢账号 | 是否误用 `STORAGE=memory` 或未设 `DATABASE_URL` |
| 409 sync_conflict | 正常乐观锁；客户端应先 GET 再合并 PUT（App 已处理） |
